SmallDocs:
a smaller way
to publish.

Markdown, notebooks, and Python API docs. Quarto conventions. And themes that reach from Bootswatch to Tufte.

Rahul Dave/October 16, 2026

IN THIS NOTE

A familiar folderOne site, many themesThe Tufte themeNotes in the marginTry itWhere it fits

SmallDocs is the first project on the Smallish workbench: a Python package that turns a folder of pages into a website. Its starting point is the material you already have—Markdown, notebooks, and the configuration of a Quarto website.

A small project still deserves somewhere clear to explain itself. A guide should have navigation. A long page should have a table of contents. Code examples, figures, and API reference pages should be easy to read. SmallDocs brings those pieces together in a website generator you can install with Python.

Start with a familiar folder

SmallDocs reads .md, .qmd, and .ipynb files. A native project uses _smalldocs.yml; an existing Quarto project can keep its _quarto.yml. With your pages and configuration in a folder called docs/, the basic workflow is below. You need Python 3.11 or later.

IN YOUR TERMINAL

pip install smalldocs
smalldocs render docs
smalldocs preview docs

The render command writes the website into docs/_site/ by default. Preview serves it locally and reloads the browser when you edit. The getting-started guide walks through the folder and its first page.

The familiar structure continues inside the site: a navbar, a sidebar, a table of contents, search, and links between pages. There are callouts, maths, tabsets, and listings for collections of pages. Python projects can generate API reference pages from code, and notebooks keep their saved outputs in the published page.

One site, many themes

Choosing a theme should be a small decision you can try and revise. SmallDocs includes 25 Bootswatch themes as ready-to-use CSS. Set theme: flatly, for example, and render again. You can also use plain Bootstrap or your own CSS.

For a light/dark pair, name both themes. SmallDocs’ own documentation uses Cosmo and Darkly:

IN _SMALLDOCS.YML

theme:
  light: cosmo
  dark: darkly

On a first visit, the site follows the reader’s browser preference. A switch in the navigation lets the reader choose a mode, and the browser remembers that choice. In a Quarto configuration, the equivalent theme setting belongs under format.html.

The theme supplies the colours and typography; SmallDocs supplies the page structure. That separation also makes room for a more distinctive theme.

The Tufte theme

smalldocs-tufte is a theme extension for both SmallDocs and Quarto. It takes its visual language from Tufte CSS: ET Book type, a warm paper background, a measured text column, and restrained rules and links. The extension also includes a dark mode.

It suits pages that ask for close reading: an explanation with figures, a technical note, or an essay whose asides belong near the sentence they qualify. The type gives the page a bookish character while the navigation still works like a website.

Put notes beside the argument

The margin is useful space. In the example at the top of this post, numbered footnotes sit beside the paragraph that cites them. An unnumbered note adds context, and the chart’s caption sits beside the chart. The reader can move between the explanation and its supporting material without jumping to the bottom of the page.

SmallDocs implements the layout; the Tufte extension gives it the theme’s appearance. Set reference-location: margin to place footnotes beside the text, or fig-cap-location: margin for figure captions. A .column-margin div holds an unnumbered note, and an .aside span adds a short aside. Wider figures can use .column-page.

These are Quarto-style conventions, so the source stays readable as ordinary Markdown. On a narrow screen the notes follow the relevant text instead of being squeezed into a side column. The side-notes demo shows the result; the margin and wide-content guide explains the markup.

Try Tufte in your project

From the parent of your docs/ folder, add the extension. This step needs Git; the public HTTPS URL works without an SSH key:

IN YOUR TERMINAL

smalldocs add https://github.com/rahuldave/smalldocs-tufte.git --dir docs

Then use it in docs/_smalldocs.yml. The extension supplies both its light and dark stylesheets:

IN DOCS/_SMALLDOCS.YML

theme: tufte
reference-location: margin
fig-cap-location: margin

The command copies the extension into docs/_extensions/tufte/. Keep that folder with your project so future builds use the same theme. SmallDocs uses the extension’s compiled CSS and font assets; it does not need a Sass compiler to render the site. See the theme-extension guide for the supported sources and update commands.

The same extension repository also supports Quarto through its tufte-html format. The installation guide gives the settings for each tool.

Keep the scope clear

SmallDocs builds websites. It shows the outputs already saved in a notebook, and it does not execute notebook cells during a render. Keep execution in your notebook workflow. If you need PDF, Word, slides, or other Quarto capabilities, choose the tool that handles those requirements. The Quarto compatibility guide describes the boundaries, and smalldocs render docs --strict makes a warning fail the build.

For a guide, a project site, or a collection of technical notes, SmallDocs offers a practical starting point: familiar files, a Python install, and a choice of reading styles. Start with the page you want someone to read, then choose the theme that serves it.
