SmallDocs.

Build a website from your words,
notebooks, and ideas.

SmallDocs generates websites in pure Python. It follows the page and configuration formats of Quarto, a publishing tool. Use your Markdown files, Quarto (.qmd) pages, or notebooks. If you have an existing _quarto.yml configuration, you can reuse it. For your first site, follow the "Read the docs" link below.

Read the docs ↗ Compare themes ↗ View source ↗

Choose from three custom designs and five Bootswatch themes adapted for reading. Bootswatch is a collection of Bootstrap themes. Compare all eight with their original versions.

Install or update a theme ↗ Theme handbook ↗ Typography assessment ↗ UI design assessment ↗

The typography and UI design guides explain principles for choosing and customizing fonts, spacing, colors, and layouts.

smallish dev.

Tools for agents
that ship code.

smallish dev sets up a project so that a person and an AI agent work the same way. Every command is a recipe of just, a command runner, and each recipe line goes into a run log. Before a commit, a Git hook reads that log and, for a commit by an agent, the review records. It stops a commit that has no proof of its checks.

Read the docs ↗ Start a fresh folder ↗ View source ↗

The stack: jnterfaces, the installer; the Python, TypeScript, and Rust profiles; agent_gest_git_skills, the skills and commit gates; jlog, the run log; gest, the tasks; jagt, the hand-off to an agent; cx, lines that run again only when their files change; and nossaifd, the writing guide.
